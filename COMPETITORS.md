# Hallmark counterpart selection

Reviewed 2026-11-20. This register covers 50 product and specification profiles across the delivery lifecycle, including the Dhall and MCP standards.

The requirements include acceptance conditions for selected ideas and consumer-driven refinements. The counterpart source register records URLs, review kind, requirement mappings and pinned source-file identities. [Requirements](REQUIREMENTS.md) · [Consumer requirements](REQUIREMENTS.md#requirements-from-ecosystem-consumers) · [Source register](competitive-sources.json).

Adopt means an original Hallmark contract. Integrate means a candidate adapter, with its exact version, edition, license and capability to qualify. Defer means no dependency or first-slice implementation commitment. Documentation/source inspection is not runtime parity. No upstream implementation is included in this repository change.

## Important selection boundaries

- Atlas currently documents `migrate lint` as Pro from v0.38. Its safety-analysis pattern is useful; an open-source-only adapter cannot assume that command is available. [Atlas lint documentation](https://atlasgo.io/versioned/lint).
- The inspected Liquibase license is FSL-1.1-ALv2, not an assumption of Apache-2.0 for the inspected version. Keep the precondition idea; select a runtime separately. [Pinned license](https://github.com/liquibase/liquibase/blob/d0e1304f5f31be5df0bdd25f42cf195aad521fb1/LICENSE.txt).
- GitLab review apps are documented across Free/Premium/Ultimate; protected-environment deployment approvals are Premium/Ultimate. [Review apps](https://docs.gitlab.com/ci/review_apps/), [deployment approvals](https://docs.gitlab.com/ci/environments/deployment_approvals/).
- Unleash documents environment creation/cloning/deprecation/deletion as Enterprise features. Provider-neutral flag evaluation does not make those server features available. [Unleash environments](https://docs.getunleash.io/concepts/environments).
- Octopus snapshots release process/package inputs but excludes tenant variables from that snapshot. Hallmark must identify resolved tenant configuration separately. [Octopus releases](https://octopus.com/docs/releases).
- The inspected Changesets main branch says it is v3 development; v2 has a maintenance branch. Dagger documentation is marked 1.0-beta, and Nix marks the inspected flakes interface experimental. Pin a supported implementation before building an adapter. [Changesets source](https://github.com/changesets/changesets/blob/9a035ec36045aeb6141dd0bbac9ab9e3c69ac0bc/README.md), [Dagger glossary](https://docs.dagger.io/reference/glossary/), [Nix flakes](https://nix.dev/manual/nix/2.34/command-ref/new-cli/nix3-flake.html).
- OpenTofu documents backend-dependent state locks; the inspected Locker contract does not require protection against non-cooperating writers. Distributed target fencing is an additional requirement. Its encryption documentation also explicitly distinguishes confidentiality from replay protection. [Lock contract](https://github.com/opentofu/opentofu/blob/0183949c60df4ce6b6268e0b6e2a2acc40bf18a3/internal/states/statemgr/locker.go), [encryption](https://opentofu.org/docs/language/state/encryption/).
- Traffic debugging through Telepresence/mirrord, registry artifact copying and a tenant environment capture solve different problems. No one of these qualifies the other two. [Telepresence](https://telepresence.io/), [mirrord source](https://github.com/metalbear-co/mirrord/blob/c8ded0d15e27ac33c47838f7ff9d5b234e749bbe/README.md), [ORAS](https://oras.land/docs/), [Velero restore](https://velero.io/docs/v1.19/restore-reference/).
